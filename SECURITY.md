# Security Policy

Please do not disclose suspected vulnerabilities publicly through GitHub issues.

For security-related matters, contact VND TECH LLC through the official website:

https://vndtechllc.com/

## Public Repository Safety Rules

This repository must not contain:

- Credentials, passwords, tokens, or API keys
- Private keys or certificates
- Production secrets or environment files
- Confidential infrastructure details
- Customer or user data
- Unpublished patent-sensitive implementation details

If sensitive information is discovered, it should be removed immediately and any exposed credential should be rotated through the appropriate external system.
